# Privacy

Agora is self-hosted software. There is no Agora cloud service. You run it, and you control the data. This page explains where your data goes when you do.

## What Agora stores on your machine

- **Debates.** Every question you ask, every agent message, the web sources found, the Judge's rulings, scores and the verdict are saved as files in `backend/data/debates/` (or the `agora-data` Docker volume). Delete a debate from the History panel, or delete the files, and it is gone.
- **Logs.** The backend writes JSON logs to `backend/logs/` (or the `agora-logs` Docker volume): application events, agent calls (agent, model, latency, token counts, retries, errors), web-search queries, and errors. Logs include debate ids and search query text. They do not store full agent messages. Logs rotate automatically.
- **Browser.** The web UI does not use cookies, analytics or tracking, and it loads its fonts from the app itself, not from a font service.

## What leaves your machine

Agora sends data to the services you configure in `.env`:

- **Model providers** (for example Anthropic, OpenAI, Google, Groq, OpenRouter). Your question, the debate transcript so far, and the web evidence found are sent to each provider so its agent can respond. Each provider handles that data under its own terms and privacy policy. Free tiers often allow providers to log or train on prompts, so check before using sensitive questions.
- **Tavily.** The search queries the agents write are sent to Tavily to fetch web results. Those queries are derived from your question.

Nothing is sent anywhere else. Agora has no telemetry and does not phone home.

## Your responsibilities

- Do not put personal, confidential or regulated information into questions unless you are comfortable with the providers you configured receiving it.
- Debates can contain strong language and sensitive topics. Agent output is generated by AI models, may be wrong, and does not represent anyone's views.
- If you run Agora for other people, tell them what is stored and sent, and secure the server. See [SECURITY.md](SECURITY.md).

## Deleting your data

1. Delete debates from the History panel, or call `DELETE /api/debates/{id}`.
2. Remove `backend/data/` and `backend/logs/`, or run `docker compose down -v` to delete the Docker volumes.
3. Revoke or rotate your API keys at each provider. Requests already sent are governed by that provider's retention policy.
